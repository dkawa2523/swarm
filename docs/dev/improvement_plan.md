## 責務と判定

| 所有者 | 入力と出力 | 進める条件 |
| --- | --- | --- |
| Swarmの四solver | schema v2の気体・電界・物理指定からEEDF、反応係数、対応する輸送量を計算 | solverの対応範囲と物理機能の扱いを実行計画に記録 |
| 共通の元表 | 資格付き保存結果から、E/N点と単位・由来を保持した係数表を生成 | 値、符号、欠損、統計資格を量ごとに保持 |
| COMSOL入力層 | 資格付き元表から平均エネルギー軸の係数とFunction EEDFを生成 | 独立変数の一価性、分布の非負性・モーメント、P1の有効な反応係数を照合 |
| 各COMSOL adapter | model mapとbundleを使って取込、計算、保存結果の出力を実行 | 取込照合、対象条件、収束・保存結果の判定を分ける |
| プラズマモデル | 反応係数・閉包を使って化学種、組成、場、粒子・エネルギー収支を計算 | モデルごとの条件・定常性・保存則を判定 |

元表のE/NとCOMSOL用の平均エネルギーを区別する。Globalモデルは固定した気体条件で
必要な係数を読み、組成の時間発展を自身で解く。COMSOLの結果取得と図は各adapterの
保存解を使う。通常の入口はSwarm YAMLと、COMSOLを使う場合のmodel mapである。

## Phase 8で見つけた事項

- 旧CCP変換は滑らかな中間分布への近さを測っていた。5 Tdの励起係数は有限体積の保存値
  `7.109e-19 m³/s`から`8.977e-19 m³/s`へ変わり、1 Wの周期計算後に不合格になった。
  [旧受入記録](results/argon_p1_comsol_validation_20261108.json)
- P1は元の係数を固定し、非負のEEDFをモーメント制約付きで投影する。CCPの事前計画では
  MPH内の断面積で再積分する。取込照合に失敗すると、適用済みMPHの段階で停止し、
  `external_not_started`を記録する。共通の表読込を再利用し、元係数照合の重複出力を整理した。
- 保存点を線形につないだ試作は、反応の立ち上がりを過大評価した。分布に沿った補間で
  改善したが、除外した3点では22–78%の相対差が残った。
  [実データの回帰と除外点ベンチマーク](../benchmarks/function_eedf_projection.md)
- 近接した電子エネルギー節点で、CSVの計算値とCOMSOLの評価値が一致しないケースがあった。
  出力格子の節点間隔を確保し、元断面積の節点を含む積分・誤差評価を維持した。

## 多角的レビュー

| 観点 | 確認結果 | 残件 |
| --- | --- | --- |
| 設計・拡張 | Swarm、元表、形式変換、adapterの受入を分離。新しいP1の補正は元係数と衝突カーネルを引数に取り、共通処理を使う | COMSOLの対象adapterには参照断面積のcheckout依存が残る。移動可能な独立実行を広げるときは由来と必要ファイルを同時に解決する |
| 数値計算 | 元係数・非負性・正規化・平均エネルギーを照合し、COMSOL側の取込を別に評価。正柱は導電電流を電子とイオンに分けて確認 | 反応の急増区間で追加Swarm点が必要。正柱の電子電流の局所振動は閉包と離散化を対照実験で切り分ける |
| データ・再現性 | 5、20、3500 Tdの実セル1,188行と反応9行を追加。独立積分で保存値と変換表を検証。既存[BOLSIG+照合](../benchmarks/ar_bolsig_plus_equivalence.md)は別ソルバーの数値対照 | 実験と照合するには運転条件、診断位置・物理量を一致させる |
| 利用・運用 | 元表・設定済みMPH・受入結果・保存解からの比較を区別。正柱比較は両方の保存結果にある電流成分を表示。別環境のwheelからP1 bundleの生成と正柱の図を再現 | GUI配布の判定は[配布モデル一覧](../../comsol_models/README.md)。P1実機計算はbatchで確認する |

正柱の200 V、13.3322 Pa、1 sでは外部閉包の200→400要素で電子密度は0.42%変化した。
同じ200要素で元のCOMSOL Boltzmann閉包との差は70.2%だった。400要素の外部閉包では、
電子・イオン・変位電流の最大絶対値はそれぞれ60.5、0.73、`1.46e-19 A/m²`だった。
外部ケースは基底励起・電離をSwarm Townsend表で与え、残る反応にMaxwellian EEDFを
使う。元ケースはBoltzmann EEDFで与える。[正柱の比較手順](../comsol_workflow.md)

## 次に進める内容

1. ICPの励起・電離の立ち上がりと高電界側を対象にSwarm点を追加する。区間内の別計算を
   保持し、反応係数の予測差とモデル運転域を照合してから新しいbundleを受け入れる。
2. 正柱の閉包差を切り分ける。同一メッシュ・境界条件で反応閉包を一つずつ変更する。
   閉包固定の対照では電子束の電極近傍の離散化を変え、局所束と全域収支を照合する。
3. 次の対象として現行MCの資格とCOMSOL受入を同じ運転点で取得する。実験対照は電力または
   電圧、圧力、測定位置、診断量のそろったケースから始める。
